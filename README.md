# ORV — Chapter 1 Prototype

Browser prototype for the Omniscient Reader's Viewpoint game concept.

## Current milestone

Chapter 1 / Prologue prototype:
- Interactive phone/novel opening
- Dokja-focused dialogue transition
- Scenario transition
- 2.5D/isometric-style Three.js subway environment
- WASD/arrow movement
- Basic interaction point
- Scenario HUD and probability feedback

## Run

Open `index.html` in a modern browser.

The prototype uses Three.js from a public CDN, so an internet connection is currently required.

## Direction

The project is being developed as a scenario-driven action RPG with:
- manhwa-inspired presentation
- 2.5D / stylized 3D environments
- real-time combat
- scenario progression
- Probability as a gameplay system
- knowledge/story choices affecting progression

Next milestone: build the first actual subway scenario with NPCs, scenario objectives, combat, enemy AI, and a proper Dokja controller.
